# Tecnoarreda static site

English is the default language. Italian pages live under `it/`.

## Structure

```
/
  index.html                 # English home (default)
  who-we-are/, contacts/, projects/, general-contractor/, realizzazioni/
  it/                        # Italian
    index.html
    chi-siamo/, contatti/, progetti/, general-contractor/, realizzazioni/
  assets/
    css/, js/, fonts/, images/, video/, media/, vendor/
```

## Page map

- EN (default): `/`, `/who-we-are/`, `/contacts/`, `/projects/`, `/general-contractor/` (+ subpages), `/realizzazioni/{slug}/`
- IT: `/it/`, `/it/chi-siamo/`, `/it/contatti/`, `/it/progetti/`, `/it/general-contractor/` (+ subpages), `/it/realizzazioni/{slug}/`

Open `index.html` (English) or `it/index.html` (Italian).
